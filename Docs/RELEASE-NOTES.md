Windows Performance Toolkit 0.6.0 packages the six-phase implementation with a dry-run default.

Download `WindowsPerformanceToolkit-0.6.0.zip` and its matching `.sha256` file. Review the README verification/unblocking steps before running local scripts. The manifest lists exact file hashes and source commit; checksums provide integrity, not an independent code signature.

Highlights: terminal profiles/recommendations; locally validated backed-up mouse/animation operations and restoration; performance captures, normalized external benchmark imports and reports; verified versioned offline/online installation; optional update checks.

Installation never launches the application, bypasses execution policy, disables security, or automatically applies optimizations. Native API writes require explicit local Windows validation and user confirmation. Gaming FPS/frame-time values are imported real measurements, never generated estimates.

This release is prepared as a draft after automated compatibility and package checks. Review hosted results and validate Windows behavior before publication. No Authenticode certificate or universal performance guarantee is supplied.

# Changelog

## 0.6.0 — Distribution

- Versioned ZIP packages with published SHA-256 checksums, source provenance and per-file manifests.
- Verified offline installation and explicit downloads from the fixed GitHub repository.
- Side-by-side version folders; installation never starts code or overwrites existing versions/recovery data.
- Optional informational update checks, Windows launcher and release automation.
- ZIP path/size/type validation, staged content verification and no execution-policy bypass.

## 0.5.0 — Performance comparison

Read-only Before/After captures, external normalized benchmark summaries, JSON/CSV/Markdown reports and explicit evidence limits.

## 0.4.0 — Backup and restoration

Durable session originals/history, confirmed native apply, per-setting/full rollback, interruption recovery and machine-local native validation.

## 0.3.0 — Engine

Documented mouse/animation operation definitions, original/target dry runs, permission checks and state verification.

## 0.2.0 — Recommendations

Read-only setting observations, conservative recommendations, compatibility checks and sortable comparisons.

## 0.1.0 — Terminal interface

Dashboard, hardware information, seven profiles, 18 documented options, checklists and simulation history. Subsequent fixes addressed Windows PowerShell 5.1 script-root timing and JSON enumeration.
